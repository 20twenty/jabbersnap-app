# Jabbersnap

Speak quietly. Capture screenshots, selected text, and links as you go.
Jabbersnap puts everything together into one clear prompt you can send to an AI.

**jabbersnap.com**

## What this repository is for

This is where Jabbersnap's public downloads and issue tracking live.

- **[Releases](../../releases)** — the Jabbersnap Mac app, once it is available
  to download.
- **[Issues](../../issues)** — bug reports and feature requests for the Mac app
  and the device.
- **[Discussions](../../discussions)** — questions, ideas, and anything that is
  not a specific bug.
- **[Privacy policy](PRIVACY.md)** — what the app sends off your Mac and what
  stays on it.

Jabbersnap's source code is not public, so there is nothing here to build and
no pull requests to open. The repository exists so that reporting a problem does
not require an email thread.

## Status

Jabbersnap is in development for Mac and is not yet offered for sale. There are
no releases yet. Product details remain subject to validation.

## Reporting a problem

Open an [issue](../../issues/new/choose) and pick the template that fits. The
templates ask for the version and system details that make a report
reproducible — the more of them you can fill in, the faster it can be diagnosed.

Issues here are public. Please leave out personal data and the contents of any
real prompt — a redacted example is usually enough to reproduce a problem.

Security vulnerabilities go through
[private vulnerability reporting](../../security/advisories/new) instead, so the
report stays confidential until a fix ships.
